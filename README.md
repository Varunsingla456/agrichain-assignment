This project is the Agrichain assignment. It has two problems, and both are about the same task: given a string, find the length of the longest part that has no repeated character.
Problem 1 is a Java program in problem1/LongestSubstringTest.java. The program asks you to type a string and then prints the length. For abcabcbb the length is 3, because abc is the longest part with no repeated character. From the problem1 folder, compile it with javac LongestSubstringTest.java and run it with java LongestSubstringTest.
Problem 2 is the testing part for a website that does the same job. problem2/TEST_CASES.md is the list of test cases, some to do by hand and some to automate. problem2/automation is a Cucumber script for one case: open the input page, type abcabcbb, click Submit, and check the result page. From the problem2/automation folder, run it with mvn test.
